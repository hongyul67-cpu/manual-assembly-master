## 수업 슬라이드

원고는 `lesson.js`, 화면(뷰어)은 **links 의 공용 `board-pro.js`** 입니다. 뷰어를 이 저장소로 복사하지 않습니다.

```html
<script src="lesson.js"></script>
<script src="https://hongyul67-cpu.github.io/links/board-pro.js"></script>
```

배우기(개념 카드 45장)는 학생이 혼자 폰으로 읽는 것이고, 슬라이드는 교실 앞에 띄우는 것입니다.
**둘은 별개의 한 벌이라 배우기를 지우거나 줄이지 않았습니다.**

그림은 새로 그리지 않고 `index.html` 이 이미 가진 것을 불러 씁니다 —
`SVGT`(공구 12종) · `SYM`(기호 53종) · `drawCaliper()` · `drawMic()`.
`SYM` 은 획이 짙은 색이라 검은 슬라이드에서 보이지 않으므로 `lesson.js` 의 `box()` 가 흰 판 위에 얹습니다.
**이 흰 판을 빼지 마세요.**

## 고칠 곳

`index.html` 위쪽의 `LEARN`(개념 카드) · `QUESTIONS`(문항) · `TOOLQ`(공구 고르기) ·
`ORDERQ`(조립 순서) 네 배열만 고치면 됩니다. 그 아래 엔진은 대개 건드리지 않습니다.

공유압 기호는 `SYM`(기호 하나 = SVG 문자열 하나)과 `SYMGROUP`(기호가 속한 무리),
`SYMWHY`(어떻게 알아보는지 — 채점 뒤에만 보임) 세 곳에 나뉘어 있습니다. 셋 다 채워야 합니다.
무리는 게임에서 **오답 보기를 뽑는 범위**입니다. 무리가 다르면 눈으로도 답이 보이므로 반드시 같은 무리로 묶습니다.

눈금 그림은 `drawCaliper()` · `drawMic()` 가 값에서 직접 그립니다.
문제마다 값을 새로 뽑으므로 문항을 따로 만들 필요가 없습니다.
